# StayNest

## Project Overview
StayNest is a Flutter-based room, hostel, and rental accommodation finder application for Nepal.

The platform connects customers searching for rooms with property owners who want to list accommodations.

## Technology Stack
- Flutter
- Dart
- Material Design
- Local data services

## User Roles

### Customer
- Browse rooms
- Search rooms
- Filter rooms
- Save favorite rooms
- Send inquiries
- Manage profile

### Owner
- Add room listings
- Manage listings
- View inquiries
- Update room availability
- Manage owner profile
